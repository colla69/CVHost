# DNS records for colarietitosti.info that CDK creates in Route 53, beyond the
# ones CvHostSite owns (the cv / apex / www aliases and the ACM validation records).
#
# Read by two things:
#   - infra/lib/dns-stack.ts       creates them in Route 53 via CDK
#   - scripts/aws-infra.sh verify  diffs them against live DNS
#
# Format, one record per line, '#' starts a comment:
#   name   TYPE   TTL    value          '@' = zone apex
#   @      MX     3600   10 mx.example.net.;20 mx2.example.net.     ';' separates values
#
# An unsupported TYPE throws at synth time rather than being skipped -- a record
# silently dropped here is a name that silently goes dark.
#
# Empty on purpose since the Strato exit (STRATO-EXIT.md, Phase 3). This file used
# to mirror the Strato zone: the apex A, a wildcard CNAME and eight subdomains, all
# pointing at the Strato box 85.214.103.161. The box is gone with the Strato
# account on 2026-11-02, and Strato hands its IP to another customer. A record left
# pointing at it would let that customer serve pages -- and obtain a certificate --
# for a name under this domain. So none of them may come back, the wildcard least
# of all: it answered for every name nobody had thought of.
#
# The apex and www now redirect to cv at CloudFront; see SiteStack.
